The Salesforce integration connects the Interface Web Component to the standard `Event` object through an LWC and Apex controller. It is a **beta** release, separate from the npm packages.

**Lightning Web Security is required.** Legacy Lightning Locker does not support the third-party custom elements used here. See [LWS compatibility](/docs/salesforce/locker-service).

## Data flow

`Event` records → user-mode Apex query → LWC snapshot → `<forcecal-main>`.

User create/edit/delete actions → guarded LWC handlers → user-mode Apex writes → refreshed authoritative records.

The 0.3 integration bundles Core 2.5.6 and Interface 1.9.0. Deploy the LWC, controller and static resource together: the LWC now calls date-aware `createCalendarEvent` and `updateCalendarEvent` methods.

## Supported workflows

- Month, week and day views with date navigation and refresh
- Event creation, existing-event details/editing, cancellation and confirmed deletion
- Location and description transport
- Record-page filtering and creation: Contact/Lead use `WhoId`; supported other records use `WhatId`
- Inclusive all-day start/last-day dates, including same-day events and timed conversion
- Read-only UI/persistence guards and independent Apex permissions
- Optional controller-only Access, Reader and Editor permission sets

Fetched snapshots do not trigger Apex writes. Writes retain record identity, queue changes for the same record, and reconcile rejected mutations. Native Salesforce recurring events are displayed but remain read-only here; use Salesforce Calendar for series/occurrence changes. Production color selection is hidden because no custom color field is mapped.

## Verification boundaries

The October 0.3 candidate passed 38 LWC tests in UTC, Los Angeles, Kolkata and Auckland using the real bundled Interface with mocked Apex transport. Isolated Apex tests exercise actual Reader/Editor sets, denial paths and sharing. Live synthetic Event tests verified timed CRUD, cancellation, refresh/navigation, inclusive all-day dates and all-day-to-timed conversion; fixtures were removed.

A restricted-user Lightning browser session and live forced network-failure scenario have not been verified. There is no comprehensive security audit or assistive-technology certification claim. See the [source verification record](https://github.com/forceCalendar/salesforce/blob/2148bb4f/docs/VERIFICATION.md) and [beta installation status](/docs/salesforce/deployment).
