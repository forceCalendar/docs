## All Public Classes

Unless marked internal, these classes are exported from `@forcecalendar/core`:

### Core

| Class | Import | Description |
|-------|--------|-------------|
| [Calendar](/docs/api/calendar) | `@forcecalendar/core` | Main calendar controller |
| [EnhancedCalendar](/docs/api/enhanced-calendar) | `@forcecalendar/core` | Calendar + search + recurrence v2 |

### Events

| Class | Import | Description |
|-------|--------|-------------|
| [Event](/docs/api/event) | `@forcecalendar/core` | Event model |
| [EventStore](/docs/api/event-store) | `@forcecalendar/core` | Indexed event storage |

### Recurrence

| Class | Import | Description |
|-------|--------|-------------|
| [RecurrenceEngine](/docs/api/recurrence-engine) | `@forcecalendar/core` | Static recurrence expansion |
| [RecurrenceEngineV2](/docs/api/recurrence-engine-v2) | `@forcecalendar/core` | Instance expansion and modified occurrences |
| [RRuleParser](/docs/api/rrule-parser) | `@forcecalendar/core` | RRULE string parsing |

### ICS

| Class | Import | Description |
|-------|--------|-------------|
| [ICSParser](/docs/api/ics-parser) | `@forcecalendar/core` | Low-level ICS parser |
| [ICSHandler](/docs/api/ics-handler) | `@forcecalendar/core` | High-level ICS operations |

### State

| Class | Import | Description |
|-------|--------|-------------|
| [StateManager](/docs/api/state-manager) | `@forcecalendar/core` | Immutable state management |

### Search

| Class | Import | Description |
|-------|--------|-------------|
| [EventSearch](/docs/api/event-search) | `@forcecalendar/core` | Full-text search |
| [InvertedIndex](/docs/api/inverted-index) | `@forcecalendar/core` | Synchronous search index |
| [SearchWorkerManager](/docs/api/search-worker-manager) | `@forcecalendar/core` | Web Worker search |

### Utilities

| Class | Import | Description |
|-------|--------|-------------|
| [TimezoneManager](/docs/api/timezone-manager) | `@forcecalendar/core` | Timezone operations |
| [ConflictDetector](/docs/api/conflict-detector) | `@forcecalendar/core` | Event conflict analysis |
| [DateUtils](/docs/api/date-utils) | `@forcecalendar/core` | Static date utilities |

### Performance (internal)

These classes are documented for reference but are **not** exported from the `@forcecalendar/core` package entry point. They are internal utilities used by `EventStore` and `EnhancedCalendar`.

| Class | Access | Description |
|-------|--------|-------------|
| [PerformanceOptimizer](/docs/api/performance-optimizer) | Internal (e.g. via `calendar.eventStore.getPerformanceMetrics()`) | Caching and metrics |
| [LRUCache](/docs/api/lru-cache) | Internal (used by PerformanceOptimizer) | O(1) LRU cache |

## Import Patterns

```js
// Everything from main entry
import { Calendar, Event, EventStore, TimezoneManager, ConflictDetector } from '@forcecalendar/core';

// Specific subpath exports
import { Calendar } from '@forcecalendar/core/calendar';
import { Event } from '@forcecalendar/core/events';
import { StateManager } from '@forcecalendar/core/state';
import { EventSearch } from '@forcecalendar/core/search';
import { ICSHandler } from '@forcecalendar/core/ics';
```
